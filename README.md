# 方成教育 Fcdraw

面向安卓教学大屏与会议屏的白板。品牌官网：http://www.fcjyboard.com/

安卓版最低 Android 8.0（API 26），与内置 Moonshine 原生库的官方要求一致。

- 唯一底栏：原绘图工具、撤销重做、缩放、文件菜单、素材库、语音、截屏、录制、课件与设置集中在同一条工具栏。未展开浮层时，其余区域全部用于白板；窄屏可横向滚动工具栏。
- AI：默认火山方舟 Chat Completions 接口，可自定义兼容接口。首次使用填写实际模型或接入点 ID 与密钥；截图分析需要视觉模型。框选时分析选区，否则分析整个白板。
- 数学：书写 `1+1=` 后停笔自动补全，或直接圈选算式计算；支持本地数值、复数、`diff(x^3,x)`、`integrate(sin(x),x)`、`defint(x^2,0,1,x)`、`limit(sin(x)/x,x,0)`、`solve(x^2-1,x)`。手写识别需要配置视觉模型；设置中可关闭自动计算。识别结果可能需要更正，不保证所有数学问题均可求解。
- 函数：用原有框选或套索选中表达式，直接点击出现的“绘制函数”；二维曲线和三维曲面网格均为可编辑、可擦除的白板对象。生成后调节 x/y 采样平移、z 输出偏移及 a/b/c 参数；关闭浮层后重新选择图像，可以继续调节，参数随白板保存。
- 语音：安卓版默认内置 Moonshine 中文 Tiny Streaming 模型，无需系统语音服务、账户、密钥或首次下载。系统识别与自定义音频转写接口为可选项。说“帮我画个立方体”“画 y 等于 x 加一的函数图像”“计算一加一”可直接执行；复杂意图、手写计算和总结使用配置的视觉 AI。浏览器版可选择系统语音或自定义接口。
- 录制：麦克风、麦克风与摄像头、麦克风与白板画面、三者组合。画面模式录制应用画布。录制可继续书写，在本机保存，支持回放、下载、时间轴文稿和 AI 总结。内置识别与录制共用麦克风，并可在录制中点击语音按钮执行下一条指令。系统识别并发能力取决于设备。离线重新转写支持设备可解码、30 分钟以内的音轨；长录制保留实时文稿，也可使用自定义转写。
- 局域网快传：安卓安装版开启本地接收服务，在同一网络的手机浏览器打开带随机配对码的地址上传；单文件 100 MB，支持 PPTX、PDF 和图片。关闭接收即停止服务。浏览器版可打开本机文件。PPTX 使用第三方预览包，复杂 Office 特效可能存在兼容差异；PDF 取决于设备预览能力。

使用 pnpm 10.28.2 安装依赖。验证命令：`pnpm check`、`pnpm lint`、`pnpm test`。不包含 Cargo。应用内部保留上游包名和文件格式标识，以兼容已有白板文档；第三方版权归其所有者，品牌不代表第三方代码原创。

推送 main 后，GitHub Actions 执行检查、lint、测试、生产页面浏览器验证、Web / 安卓调试 APK 打包，以及 Android 单元测试、lint 和离线模型模拟器测试。模型固定版本及校验信息见 `scripts/speech-models.json`，构建时校验并打进 APK。工作流全部成功后从 Artifacts 下载 `Fcdraw-Android-APK`；`Fcdraw-UI-verification` 含不同屏幕尺寸的截图。调试 APK 可直接安装测试；商店发布签名需另行配置自己的密钥。

浏览器自定义接口需允许 CORS，录音需要 HTTPS 或 localhost。API 密钥默认仅存当前会话，勾选记住后才保存在本机。白板截图和音频只在相关 AI/转写操作时发送至配置的服务。

可选语音播报：设置 IndexTTS / 自定义播报地址后，AI 回答和录制总结中会出现朗读按钮。官方 IndexTTS 依赖 Python/PyTorch，播报引擎运行在局域网电脑；安卓 APK 内置的是中文语音识别。部署方法见 [IndexTTS 适配器说明](services/index-tts/README.md)，七个参考项目的逐项实现依据见 [参考检查记录](docs/reference-review.md)。
