# 方成教育 Fcdraw

面向安卓教学大屏与会议屏的白板。品牌官网：http://www.fcjyboard.com/

- 底部工具栏：AI 助教、数学、函数实验室、语音指令、录制、课件与设置。
- AI：默认火山方舟 Chat Completions 接口，可自定义兼容接口。首次使用填写实际模型或接入点 ID 与密钥；截图分析需要视觉模型。框选时分析选区，否则分析整个白板。
- 数学：本地数值、复数与符号计算；支持 `diff(x^3,x)`、`integrate(sin(x),x)`、`defint(x^2,0,1,x)`、`limit(sin(x)/x,x,0)`、`solve(x^2-1,x)`。手写识别依赖视觉模型，识别结果可能需要更正；不保证所有数学问题均可求解。
- 函数：二维曲线、三维曲面网格，调节 x/y 采样平移、z 输出偏移和 a/b/c 参数。图形是白板对象，可编辑、撤销和擦除。
- 语音：安卓系统识别或自定义兼容音频转写接口。系统服务是否支持离线识别取决于设备；浏览器语音取决于浏览器支持。
- 录制：麦克风、麦克风与摄像头、麦克风与白板画面、三者组合。白板画面模式录制应用画布，不采集其他应用。录制在本机保存，可回放、下载、按文稿时间跳转及总结；自定义转写接口支持 segments 时间戳时提供精确时间轴。安卓系统语音与录音并用能力取决于设备，失败时可使用录制后转写。
- 局域网快传：安卓安装版开启本地接收服务，在同一网络的手机浏览器打开带随机配对码的地址上传；单文件 100 MB，支持 PPTX、PDF 和图片。关闭接收即停止服务。浏览器版可打开本机文件。PPTX 使用第三方预览包，复杂 Office 特效可能存在兼容差异；PDF 取决于设备预览能力。

使用 pnpm 10.28.2 安装依赖。验证命令：`pnpm check`、`pnpm lint`、`pnpm test`。不包含 Cargo。应用内部保留上游包名和文件格式标识，以兼容已有白板文档；第三方版权归其所有者，品牌不代表第三方代码原创。

推送 main 后，GitHub Actions 先执行检查、lint 与测试，再打包 Web 和安卓调试 APK 并执行 Android 单元测试与 lint。成功后从工作流的 Artifacts 下载 `Fcdraw-Android-APK`。调试 APK 可直接安装测试；商店发布签名需另行配置自己的密钥。

浏览器自定义接口需允许 CORS，录音需要 HTTPS 或 localhost。API 密钥默认仅存当前会话，勾选记住后才保存在本机。白板截图和音频只在相关 AI/转写操作时发送至配置的服务。
