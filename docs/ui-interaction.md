## 当前行为

- 主菜单保持六项。AI 总结、课堂录制、快传、AI 问答在原工具箱中，沿已有命令执行；语音和截屏收在“更多工具”。固件提供快传时使用原应用，缺失时显示内置文件接收，避免重复入口。
- 主操作、笔 / 橡皮、插入、工具箱、圈选、设置、录制和分享界面使用现有 `t / useI18n`。英语、简体、繁体有新增文案；其他语言使用核对过的原 APK 可用标签及英语回退。用户已有文字、资源名称和已保存板名保持原内容；新白板、导图和计时器文字按当前语言生成。
- “跟随系统语言”通过 navigator 检测并监听 languagechange，自动检测结果不再保存成手动语言。支持地区别名与简繁识别；用户明确选择语言后保留该选择。旧的手动缓存继续兼容。
- 弹层定位使用稳定的 data 标记，切换语言不会丢失锚点。录制、问答等从工具箱锚定，设置与分享从菜单锚定；弹层限制可用宽高。圈选表格或教具时保持小型 AI 操作条，避免再叠加大属性面板。
- 白板上的回答按实际文本 / 字形边界布局；表格、导图、教具、插图、函数和坐标系插入前检查尺寸、已有对象与底栏预留区。可见区域放不下时向近处空白区域延伸，再用现有视口 API 同时展示结果与选区；已有对象坐标保持不变。已有对象的配置更新保留原位置。
- 出厂式双指手势使用前一中心作为缩放锚点，按一次真实中心位移平移，消除旧的两倍位移补偿。增量基线使达到缩放边界后的回缩立即生效；普通多人书写继续使用独立触点，不进入捏合。
- 硬笔与钢笔分别记住粗细。切换钢笔后改粗细，再切回硬笔恢复之前值；触控和 AI 样式命令共用切换逻辑。粗细滑块使用原整数范围，设备返回的上限不受 DPR 换算影响。

## 验证与边界

专项测试覆盖主菜单数量与工作流归属、工具箱真实命令、快传去重、英语 / 德语切换、系统语言变更与手动语言保留、重复插入避让、换缩放后的底栏预留、拥挤场景展示结果、圈选表格不弹属性、实际指针捏合及实际落笔宽度。完整检查结果记录在 history.md。

新增 Java 需要 CI 编译和设备校准。当前缩放使用视口变换；原 APK 使用对象矩阵变更，这一差异需要继续对照后续落笔与操作。课件专用插入布局、三指以上变换、双笔尖、圆规 / 三角尺完整交互、非笔迹局部透明擦除、原生加速与物理延迟仍有缺口。没有安装本轮新 APK，也没有完成全部原版功能或 90% 体验认证。

## 本轮补充

- 主菜单首次保存前没有文件句柄时，使用已有另存动作创建文件，避免“保存”整项消失；原有文件继续保存到原句柄。
- 课件、教师、协作状态、运行错误、动态提示与遥控页面新增文字接入现有语言系统；系统语言变化可刷新界面，显式语言选择保留。英文 / 简繁中文补齐新增标签，其余语言按现有机制缺项回退英文，不能称为所有语言均人工翻译完整。
- 231 项教学资源复用原 APK 的 216 组名称，覆盖 57 个项目语言文件；保留原 ID 和分类，支持源名称 / 当前语言搜索，PhET 打开时采用当前语言。新增德语资源搜索 / 打开与学科筛选回归。
- `layout_min_web_window.xml` 与 `HMinWebWindow.java` 指明 400×600dp 上限和底部四个 40dp 图标（8dp padding / 两侧 margin）。新原生网页窗口复用三个原矢量图标、前进旋转 180°，启用相同网页缩放设置，按可见屏幕收缩，窗口外可操作白板；原生标签随系统或显式界面语言读取资源。新增 Java 仍需 CI / 真机验证。
