## 2026-10-27 当前进展

以用户最新指定的 `ss/HWhiteBoard-reference` Java、资源和 IMG_1251–1279 为主要依据。下表已更新；后面的日期章节保留调查过程，旧 CircleToSearch 方案已由原厂圈选实现取代。本轮本地不运行 build / dev / Gradle / Cargo；用户已授权完成实现和本地检查后提交推送，由 CI 构建并验证生产页面与原生代码。最新提交和验证结果见 history.md，不能引用历史 CI 证明当前改动。

- 圈选按真实手划轨迹逐点显示一条开放路径，松手按区域命中完整对象，复合图形 / 插入 / 函数 / 语言对象保持同组；不裁成多个笔画。选择后按对象实际范围显示单个操作框，内部移动、四角缩放、复制、删除、搜索和取消共用主板 / 课件坐标与历史。
- 活动笔迹独立叠层增量绘制，静态场景不再随每个移动样本全量重播。普通笔原厂尾锋与固件开关接到 Canvas / SVG / 导出 / 擦除；长笔画边界计算移除参数展开，避免大点集 RangeError。手掌接触变大时可从写字转擦除；对象擦除使用实际尺寸和扫掠区域。
- 原画笔首页八项、额外 AI 笔分页、橡皮左右模式开关 / 滑动清屏、紧凑三列工具和分页、20 种图形选后拖拽、聚光灯及尺规交互均有代码与回归。教学资源、设置、画布预览和分享按所给图片调整；逐像素视觉、触感和物理延迟仍未验收。
- AI 插字按源字号缩小 10%，优先等号右侧可见空位；本地验证算式。选区截图附件默认关闭，可在设置开启，文字与图形请求均遵守。表格接收手写并按行列扩展；思维导图 / 四线格手写先呈现真实候选，确认才替换，导图节点可拖动及增删。
- 语音和教师使用同一组件命令：只有当前请求自己的开课件 / 翻页 / 换板可继续，用户手动换目标仍取消旧任务。录制与独立指令监听衔接，停止保存后可继续接受下一句；每批模型工具执行后读取真实结果与界面，再完成或修复剩余操作。可见 UI 控件和 HTML 图形实验分别通过真实控件 ID / 版本操作。
- 助手、教师、手写提问和课程工具使用显式父子请求归属；允许自己的目标转换，仍拒绝取消、兄弟请求和手动切换后的迟到操作。新页标题与公式不沿用旧页来源。暂停录制保留指令监听，暂停话语不进入文稿，恢复时排除暂停时长；语音关闭仍生效。

## 2026-10-25 触控与旋转续修

语音问题续修：听写文字与手写轨迹通过同一 canvas.ink / document.strokes 原子写入当前可见层，使用实际框坐标、字体测量和空位避让；ASCII 为真实笔迹，CJK 为可编辑手写字体文字，返回真实来源 ids。回答定位 / 字号 / 折叠使用这些来源，不再依赖临时浮层文字。失败重试不重复写入，改写原子替换；删除、异步字体期间换板 / 开课件 / 取消使旧请求失效。清除只删除当前失败问题，保留其他笔记；课件对象不再次触发自动识别。相关 80 项回归及完整 2060 项测试通过，含真实编辑器历史、字体迟到取消和三个缩放级别；check / 零警告 lint / 格式检查通过。问题持久化后框体让出画布触摸，页脚按钮保留。73 项生产页面仅完成发现，未启动本地服务；不等同真实麦克风准确率或整机验收。

- 底栏去掉额外底部间距，安全区外贴底。宽屏保留三组，窄屏按空间分行，手机主工具四列；翻页、撤销和侧边控件保留。原 APK 的 applyBottomBarResponsiveLayout 也按可用宽度排布，但其分屏隐藏工具的做法不满足本次全部入口可用的要求。
- 单点画笔在第二指到来前达到 40 CSS 屏幕像素路径时保持书写，否则取消临时笔迹、进入现有双指 / 多指缩放；依据 HTool.vnTouchMove 的 40 路径阈值及 HCanvas.onTouchEvent。多点笔继续多人书写；选择 / 移动沿用已有手势入口。50%–200% 限制、首次 / 末次触点中点、首指距离和、增减指重建基线均保留；不把数学匹配等同硬件时延验收。
- 更多菜单与笔属性测量整个底栏的顶部，旋转后重新定位并限制可滚动高度；长文字换行。设置保留侧栏层级，资源窄屏分类移至顶部，录制操作可换行。32 项画笔 / 手势测试与 41 项组合回归通过。
- CI 新增 11 个尺寸的边界检查，中 / 德 / 阿连续旋转时保持设置与打开的窗口，另用 Chromium 真实触摸输入验证单点捏合、已落笔锁定和多人书写。浏览器用例目前仅发现，未运行本地服务。尚未覆盖全部弹窗、课件多点手势、系统软键盘和 Android 真机旋转，状态仍为部分对齐。

原版启动后已有绿板笔迹，已保留，不清除应用数据。截图与 UI hierarchy 确认三组独立底栏、中央撤销 / 重做和隐藏按钮；布局继续据此修正。原版截图、输入与显示诊断暂存 `/tmp/fcboard-*`，不把设备数据提交仓库。当前尚待安装本轮 CI APK 对照，物理手背触摸和端到端笔迹延迟尚未量化。

## AI 接入与验收

圈选确定算式、函数沿原数学链路执行；明确问题 / 操作请求复用现有命令路由。问答写入真正可编辑的白板文本，课件打开时路由到当前批注层；总结按最新约定读取整板 / 可见课件，在居中浮层呈现并可点击全屏；讲解沿现有逐步绘图控制器。普通标题不自动改写，选区变化使过期回答失效。模型只能执行已注册命令，不能据此声称所有原版能力已实现。

AI 仍需真实模型 ID、密钥与可访问的兼容接口。修复取消信号覆盖超时、原生请求取消等待、非 JSON 网关错误；设置中可测试未保存配置，有白板内容时同时发送视觉上下文。按用户的新项目要求保留当前 fcboard 配置及会话密钥语义，不再额外回退旧 fcdraw 数据键。更换 Android applicationId 会建立独立应用沙箱，不属于同源数据兼容的保证范围。

本地检查使用 CI 同版本 pnpm 10.28.2，安装依赖时禁用脚本。当前主机 Node 26 默认的实验性 Web Storage 会影响 jsdom，测试时使用 `NODE_OPTIONS=--no-experimental-webstorage`。不运行本地 build / dev / Cargo；浏览器生产页面、APK 和设备检查需在已有 CI 或待连接设备上继续。

设备连接后先读取型号、系统、物理 / 覆盖分辨率、DPI、刷新率、输入设备与应用版本；不清除设备数据。对比相同尺寸的连续直线、曲线、拐角、小字、快速回环、不同笔型、不同宽度、手背触点、双指变换、局部擦除及撤销。还原度必须以这张功能清单和同机对照记录计算，不能以新增入口数或代码量代替。
