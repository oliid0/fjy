# Fcboard

面向安卓教学大屏与会议屏的 AI 白板。品牌官网：http://www.fcjyboard.com/ 。安卓版最低 Android 8.0（API 26）。

- 所有常驻入口集中在原底栏，绘图工具居中，图标上、简短文字下。画笔和图形单击切换，长按 / 右键 / Shift+F10 打开原属性，点画布关闭；圈选工具长按切换套索。浮层锚定实际工具或对象，函数参数优先放在图像侧边，重新点选图像可呼出。窄屏工具栏横向滚动。
- 默认背景增加墨绿和黑色，切换时启用白笔，回到浅底恢复深笔；深色界面不再把这两种板面反色。
- 点击语音，或打开 AI 输入框，直接说 / 输入要做的事。绘图、插入文字、移动或擦除选区、修改颜色、调参数、新建白板、翻课件、开启板书、录制与教学使用同一套真实组件命令。常见明确命令本地执行；复杂意图由配置的模型解析，失败会显示原因。
- 书写 `1+1=` 后停笔自动补全，圈选算式直接计算，圈选 `y=...`、`f(x)=...`、`z=...` 直接生成函数图。函数参数随对象保存，选择后直接调整。数值与复数使用 mathjs，微积分、极限与方程使用 nerdamer；手写识别需要配置视觉模型。符号系统和模型均有能力边界，不保证任意数学问题可解。
- 对当前题目说“讲解这一步”“为什么”“换个例子”，AI 会在共享白板或课件板书层逐步写推导、公式、路径与批注，同时讲解。触碰白板或开始语音会暂停；追问写在同一块板上，回答后等待继续原课。测验支持点选或语音作答，答错会保留题目并降低讲解速度。
- 设置中可选图文语音、图形语音描述、字幕优先、易读同步高亮、每步停顿。字幕模式不依赖播报服务。课程进度保存在本机，可说“继续上次的课程”；课程内容仍受配置模型影响。
- 原素材库已换成教学工具：直尺、量角器、骰子、抽取名单、计时器、可旋转立体几何、单摆和抛体实验。插入后为普通白板对象，相关参数直接出现，语音也能操作。
- 新建白板自动保留原板；白板列表可直接切换、改名、丢弃和保存文件副本。各板分别保存元素、图片与视图，撤销历史不会跨板。
- 安卓开启局域网快传后，手机扫码，在浏览器选文件即上传。完整接收后自动上屏；正在播放课件时排队等待关闭，单文件上限 100 MB。支持 PPT / PPTX、PDF、DOC / DOCX、XLS / XLSX、ODF、文本和图片。本机文件同样可打开，无需将预览文件传到云端。
- PPT / PPTX 使用 Web-PPT 本地播放，支持翻页和引擎可识别的页内动画；其他文档使用 OpenDocument WASM 工作线程解析。点击板书开关即可在透明层书写、圈选、擦除、撤销与重做，按文件指纹和页码保存，原文件不被修改。Office 字体、动画、媒体和复杂排版可能与桌面 Office 存在差异；加密或损坏文件会明确报错。
- 文档原文按页保存在本机，讲解自动检索相关段落并附真实文件名和页码。安卓版可抓取当前课件的真实屏幕像素；浏览器端 PPT 可导出画面，其他 Office 文档提供提取文本与独立板书图像。
- 录制有麦克风、麦克风与摄像头、麦克风与画面、三者组合四种模式，录制时可继续书写。安卓课件画面通过应用窗口截图合成；浏览器支持时使用系统选屏授权。回放、下载、时间轴文稿和总结在浮层中展示。内置识别与录制共用麦克风；系统识别并发能力取决于设备。离线重转写支持设备可解码、30 分钟以内的音轨，长录制可保留实时文稿或接自定义转写。

AI 默认使用火山方舟 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`，支持自定义兼容接口。首次使用须填写真实模型 / 接入点 ID 和密钥，识别截图须选视觉模型。截图和音频仅在相关 AI / 转写操作时发送到配置的服务。密钥默认仅存会话，选择记住才保存在本机。

安卓版内置 Moonshine 中文 Tiny Streaming 模型，无需系统语音服务或首次下载；系统语音和自定义接口为可选项。IndexTTS 官方引擎为 Python / PyTorch，可使用提供的[局域网播报适配器](services/index-tts/README.md)，没有把该服务冒充为安卓内置语音合成模型。未配置播报或设备无声音服务时仍可使用字幕教学。浏览器录音需要 HTTPS 或 localhost，自定义服务需允许 CORS。

底栏“协作”由安卓大屏直接开启本地会话，其他设备扫码即可在浏览器共同书写；元素、图片、删除和撤销同步，持续书写期间每 40 毫秒合并发送。并发沿用原 Excalidraw 版本 / nonce 规则，断线重连和恢复前台会补齐状态。每个会话共享当前一块白板，切换白板会离开 / 结束协作并保存本机内容；旧的云端协作仍需自行配置后端。

底栏“控制”是整机 Scrcpy 控制：大屏显示一次性、五分钟有效的配对码；手机扫描链接输入后，在手机填写大屏无线调试主页的连接端口，以及“使用配对码配对设备”对话框中的配对端口和安卓配对码。安卓对话框保持打开即可完成首次配对；以后只填连接端口。Android 11 以下需要事先通过系统支持的方式授权并开启 TCP ADB。手机页面使用随包 WASM 解码 H.264，支持触摸 / 多点触摸、滚动、实体键盘、中文粘贴、返回 / 主屏 / 最近应用与全屏；控制可离开白板操作其他应用。会话以前台服务维持，通知和白板均可结束。无 root，不提供任意 shell 执行入口；受设备无线调试和输入注入权限影响，厂商限制须按错误提示在系统中开启。音频仍在大屏播放，不将设备控制宣称为远程音频转发。

使用 pnpm 10.28.2。验证：`pnpm check`、`pnpm lint`、`pnpm test:other`、`pnpm test`，不运行 Cargo。按仓库约束，本地不执行 build / dev；推送 main 后由 GitHub Actions 执行 Web 打包、生产页面交互、七种真实 Office / PDF 格式预览、APK 打包、Android 单元测试 / lint / 模拟器测试。产物为 `Fcboard-Android-APK`、`Fcboard-Web` 和 `Fcboard-UI-verification`。调试 APK 可安装验收；商店签名需使用自己的密钥。
